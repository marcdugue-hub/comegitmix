# 0007 — English as the project language

Date: 2026-11-07 · Status: Accepted

## Context
Marc speaks French with the agent for convenience, but wants the project open to the larger English-speaking world. This choice is specific to this project.

## Decision
- Docs, code, comments, identifiers, content keywords and commit messages are in English.
- The game itself stays bilingual FR/EN (see [0010](0010-product-defaults.md) for the initial language).
- Conversations with Marc may stay in French.

## Consequences
Existing French docs were translated. The brand name "Le Sens de l'IA" stays as is.
